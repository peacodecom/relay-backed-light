# Relay-backed Light 0.1.0

First stable release of the Relay-backed Light custom integration for Home
Assistant, published by [peacode](https://peacode.com).

## Features

- Create a light entity backed by one existing relay (`switch` or `light`) and
  one existing source light using the Home Assistant UI.
- Power the relay on before forwarding supported light parameters to the source.
- Configure boot delay, relay/source timeouts, and cold-start retry settings.
- Turn the relay off without intentionally waiting for a source transition.
- Cancel pending operations when superseded or when the relay turns off or
  becomes unavailable. Startup and source reconnection do not activate relays.
- Include English and German documentation, translations, and integration icons.

## Requirements and installation

- Home Assistant 2026.10.0 or later; Python 3.14.2 or later.
- An already configured relay and source light, each used by only one entry.
- Follow the [installation and setup instructions](../../README.md#installation-and-setup)
  for Marketplace, HACS, or manual installation. Back up Home Assistant first
  and restart it after installing or updating the integration.
- For manual installation, extract `relay_backed_light.zip` directly into
  `custom_components/relay_backed_light`; `manifest.json` belongs at that
  directory's root. The ZIP is attached after the release workflow succeeds.

## Validation and known limitations

- The maintainer confirmed installation using the documented instructions and
  basic operation with a physical relay and light.
- Automated CI covers lint, formatting, tests, hassfest, and HACS validation.
  The pinned Home Assistant test baseline is 2026.10.4; it is not a test matrix
  for every supported Home Assistant version.
- No claim is made that every device or failure scenario has been tested.
- Boot delays and retries are heuristics, not proof that a light is ready or a
  command was delivered. Device power-on behavior is unchanged.
- Turning off requests a power cut; it is not a safety-rated disconnection.
- Setup is UI-only. Changing the selected relay or source requires removing and
  re-adding the entry. Existing physical entity ID changes are not migrated.

See [behavior and limits](../../README.md#behavior-and-limits) for full details.
